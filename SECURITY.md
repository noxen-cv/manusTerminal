# Security Policy

## Supported Versions

This project is in early development. Security fixes will be applied to the latest main branch state.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately.

- Do not create a public issue for sensitive security reports.
- Share details through the support contact listed in `SUPPORT.md`.
- Include reproduction steps, impact, and suggested mitigations if available.

## Response Targets

- Initial acknowledgment: within 3 business days.
- Follow-up assessment: within 7 business days when reproducible.

## Disclosure

After a fix is prepared and validated, maintainers will coordinate responsible disclosure and publish release notes where appropriate.
