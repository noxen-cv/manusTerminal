# Contributing to ManusTerminal

Thanks for contributing. This project is built for developers who value minimal, text-first workflows.

## Ground Rules

- Keep changes focused and small.
- Prefer plain-text-first design decisions.
- Maintain deterministic behavior for core task parsing.
- Update docs when behavior or commands change.

## Development Flow

1. Fork and create a branch from `main`.
2. Make your change with clear commit messages.
3. Add or update tests when applicable.
4. Update `CHANGELOG.md` under `Unreleased`.
5. Open a pull request with context, screenshots, or terminal output if relevant.

## Pull Request Checklist

- [ ] Change has a clear purpose and scope.
- [ ] Documentation is updated.
- [ ] Tests are added or adjusted when needed.
- [ ] Changelog entry added.
- [ ] No unrelated files were modified.

## Code of Conduct

By participating, you agree to follow `CODE_OF_CONDUCT.md`.

## Security Issues

Do not open public issues for sensitive vulnerabilities. See `SECURITY.md`.
